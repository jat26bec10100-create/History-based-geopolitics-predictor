# Project Framework Statement

## 1. Problem Statement
Analyzing global institutional and cross-border vulnerabilities requires a balanced mathematical method. Standard risk evaluation methods frequently fail to differentiate between minor localized market fluctuations and severe systemic resource degradation, which can lead to distorted threat predictions. 

The **Geopolitical Analyser** directly addresses this structural challenge. It translates raw, qualitative global variables into quantifiable data inputs. By applying explicit linear coefficients to specific tracking vectors from scratch, the system prevents critical, high-impact issues from being overshadowed by minor economic variables. This results in an objective, reproducible numerical risk evaluation.

---

## 2. Scope of the Project
The operational scope of this computational engine is focused on a text-based terminal environment:
* **User-Interface Domain:** Terminal-based sequential command console execution loops with real-time text outputs.
* **Input Parameter Metrics:** Processes three explicit, user-supplied metrics scaling from `1.0` (Low Risk) to `10.0` (Extreme Risk):
  1. *Current Inflation Level* (Economic Instability indicator)
  2. *Current Border Tension Level* (Geopolitical Friction indicator)
  3. *Current Resource Scarcity Level* (Supply Chain indicator)
* **Algorithmic Engine Boundary:** A single-layer linear combination formula that aggregates inputs and maps them onto a percentage-based 100-point Threat Index.
* **Categorical Risk Mapping:** A deterministic boundary filter that classifies the finalized scalar index into one of three structural system categories (`CRITICAL`, `MODERATE`, or `STABLE`).

---

## 3. Target Users
This educational computational tool is designed for:
* **Academic Reviewers & Evaluators:** For validating structural linear algorithms, input parameter routing, and variable state management in standard Python implementations.
* **Systems Engineers & Researchers:** Seeking a clean, dependency-free command-line interface to simulate how hardcoded parameter weights alter composite scoring outputs.
* **Data Science Students:** Studying foundational procedural workflows, basic continuous scaling algorithms, and deterministic multi-criteria decision analysis methods.

---

## 4. High-Level Features
* **Linear Parameter Balancing Matrix:** Employs precise floating-point system constants (`0.20`, `0.30`, and `0.50`) to balance components based on their real-world impact.
* **Percentage-Based Index Normalization:** Converts continuous raw aggregates into a standardized percentage-based Threat Index scale ranging from `10.0` to `100.0`.
* **Algorithmic Category Filtering:** Automatically routes continuous numerical scores through static evaluation thresholds to finalize a risk conclusion.
* **Zero-Dependency Execution Framework:** Built using native standard Python data primitives without requiring heavy external library extensions, complex database configurations, or disk serialization.
